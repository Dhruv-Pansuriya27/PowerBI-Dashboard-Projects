# HR Analytics Dashboard

## 📊 Project Overview

The **HR Analytics Dashboard** is an interactive Power BI dashboard designed to analyze and visualize Human Resources data. It provides an easy-to-understand view of employee-related information and helps identify important HR trends and patterns.

This project demonstrates the use of **Microsoft Power BI** for data visualization, dashboard creation, and business analytics.

## 🎯 Objectives

- Analyze HR and employee-related data
- Create interactive and informative visualizations
- Identify important trends and patterns
- Present data in a simple and understandable dashboard
- Support data-driven HR decision-making

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation

## 📈 Dashboard

The dashboard provides visual insights into the available HR dataset using interactive charts, graphs, and KPI-style visualizations.

### Key Areas

- Employee Analysis
- HR Metrics
- Workforce Trends
- Employee-related KPIs
- Interactive Data Visualization
