# Sales Analytics Dashboard

## 📊 Project Overview

The **Sales Analytics Dashboard** is an interactive Power BI project created to analyze and visualize sales-related data. The dashboard transforms raw data into meaningful visual insights that can help understand sales performance, trends, and business metrics.

This project demonstrates practical knowledge of **Microsoft Power BI, data transformation, visualization, and business analytics**.

## 🎯 Objectives

- Analyze sales performance
- Identify important sales trends
- Visualize business performance using interactive charts
- Understand key sales metrics
- Convert raw data into meaningful business insights
- Support data-driven decision-making

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation
- Business Intelligence

## 📈 Dashboard

The dashboard provides an interactive view of the available sales data and presents important information through charts, graphs, and KPI visualizations.

### Key Areas

- Sales Performance
- Revenue Analysis
- Sales Trends
- Product/Category Analysis
- Business KPIs
- Interactive Visualizations

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Sales_Analytics_Dashboard.pbix` using **Microsoft Power BI Desktop**.
3. Refresh the data if required.
4. Explore the interactive dashboard.
5. Use filters and visualizations to analyze the sales data.
